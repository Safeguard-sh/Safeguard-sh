# Safeguard

Safeguard is a software supply chain security platform. It finds risk across code, open source dependencies, containers, AI models and pipelines, checks whether a vulnerability is actually reachable, and opens a tested, policy-gated fix pull request.

What it covers:

- SBOM generation and analysis in SPDX and CycloneDX, plus CSAF and VEX import
- SCA, SAST and DAST
- Vulnerability management with EPSS and CISA KEV context, and reachability analysis
- Policies, gates and guardrails enforced in CI and at release
- License compliance, attestation and signing (SLSA, Sigstore, in-toto)
- Deployment as SaaS, in a private VPC, on-prem or fully air-gapped, including a mode with no LLM in the loop
